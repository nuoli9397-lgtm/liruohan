FAQ

这是静态导出版，先看排版与风格
如何本地预览？

直接双击打开 `index.html` 即可；建议用本地小服务器预览（见 README）。

为什么不把 token 写死在网页里？

PAT 属于敏感凭证，写在前端会被任何访问者看到。这里采用弹窗输入并仅保存在本机浏览器，避免泄露。

FAQ

这页是静态 demo，先看风格与结构
这个页面的风格参考了哪里？

参考了 INFINIT 的 landing 结构（Hero + 数据条 + 分区卡片 + FAQ），并用统一的荧光绿做主色调。 参考链接：`https://infinit.tech/`

为什么不把 token 写死在页面里？

PAT 属于敏感凭证，写在前端会被任何访问者看到。这里用弹窗输入并仅保存在本机浏览器，避免泄露。

我可以继续扩展成多页面或更复杂的动效吗？

可以。先把静态风格/排版确定，再加滚动动画、案例详情页、作品集图片与更多交互，会更稳更好看。
